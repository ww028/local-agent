# 回答展示与执行记录方案

## 目的

当前回答仅基础Markdown，代码与数学公式显示不完善；工具事件以JSON裸露。
提升为可阅读的工作台组件，同时保持离线和来源真实性。

## 实现

- remark-gfm表格/列表、remark-math与rehype-katex数学排版，KaTeX字体从npm
  包本地构建，禁止CDN。代码采用本地highlight.js高亮（无外部脚本）。
- ReactMarkdown不执行HTML，图片仅占位，模型链接不直接联网；来源链接由
  可信代码以文档ID生成。所有显示文本经React转义。
- Markdown消息增加复制按钮，错误状态中文化；复制使用本地剪贴板API。
- 执行记录提供独立列表页，查询SQLite runs+会话标题，点击查看持久化事件。
  展示模型步骤、工具名、参数、结果、状态，数据JSON放details中，主界面给
  简短摘要。不显示隐藏思维，工具失败不伪造完成，删除会话同时清除记录。
- 本地静态Web仅允许已注册SPA路由，新增/runs明确允许，其他路径保持404。

## 验收

build/fonts均本地打包，Markdown表格/公式/代码可见、脚本HTML不执行，远端
图片不请求；事件重开可读、列表与删除一致。模拟测试查询/状态/权限边界，
浏览器实际打开代码公式与记录页，回归后commit，整体验收通过再push。
