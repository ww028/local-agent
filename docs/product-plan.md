# local-agent：可用产品实施总方案

## 1. 定位与交付边界

一个本地优先、运行时不依赖云服务的开源 Web Agent 工作台，代码 MIT。
第一版服务于单人、单机、可信本地文件；不是互联网多租户生产服务。
借鉴常见工作台的会话侧栏、知识区、执行卡片与参数面板，不复用任何
企业内部代码、文档、接口、图标、账号或 SDK。数据、模型、密钥不进 Git。

用户核心路径：启动 → 选模型 → 聊天；导入 Markdown → 查看索引状态 →
带来源问答；切 Agent 模式 → 自动选择受控工具 → 查看执行事件 → 得到结果。

## 2. 现有基线与处理

已完成且实测：本地模型发现、SSE 聊天、取消/错误状态、SQLite 历史恢复，
Qwen3 14B 的真实多轮测试。首先重新回归，将已验收代码提交为基线，
推送后再分模块演进。此前代码尚未提交，不把模型下载混入源码提交。

## 3. 架构

- 前端：React/TypeScript/Vite；不加载远端字体或模型输出的图片。
- API：FastAPI 单进程；SQLite 元数据/会话/运行事件，LanceDB 向量。
- 推理：Ollama loopback，仅本地模型；LLM 与 embedding 可分别配置。
- 知识模块：结构解析、切片、摘要元数据、版本/状态、混合检索、引用。
- Agent 模块：工具注册、模型结构化工具调用、参数验证、预算/取消、事件。
- 安全边界：loopback + Host/Origin 检查；无任意 shell、无任意路径读取、
  无网络抓取工具；工具只读已导入知识或计算受控表达式。

保留模型/存储适配接口。暂不使用巨大 Agent 框架，多租户/K8s/SSO不提前堆叠。

## 4. 模块顺序与方案

1. 知识库：`knowledge-design.md` → 后端管线和单测 → commit → UI/真实检索
   验收 → commit → 模块 push。
2. Agent：`agent-design.md` → 工具及持久化运行 → commit → 模型编排/执行面板
   真实验收 → commit → 模块 push。
3. 体验：`workbench-design.md` → 会话/参数/状态/来源查看/文档 → 测试 → commit
   → 产品回归及 push。

每类功能先有方案，方案解释数据流、接口、失败处理、测试及不做范围。
每批功能完成且自测通过后 commit；业务模块完整时 push。不 force push，
沿用 personal includeIf 身份，禁止任何代码贡献率采集或内部资源。

## 5. 可用性验收

- 新用户按 README 能启动，未装模型有明确提示，不静默调用云。
- Markdown（含中文/代码块/层级标题）导入、状态、预览、删除、重建可操作。
- 文档问答有真实片段来源；无证据时明确说明，不将“召回候选”冒充已引用。
- Agent 真实调用至少搜索/读取/计算中的一个工具，执行事件可重开查看。
- 取消后释放运行占用并记录状态，错误可重试，刷新历史不丢。
- 工具参数、路径/文档范围和计算预算受控，注入文档不授权新能力。
- 单测/接口/前端构建/浏览器操作/真实本地模型测试全部记录，mock和实测分开。

## 6. 不虚标完成

十几万字可索引，但“全文总结”不能只取几个相似片段。第一版 Agent
支持章节读取与基于证据回答，全文分层摘要另列后续功能，不宣称无限上下文。
多模态、PDF/OCR、任意代码执行、外部连接器、自动写文件/发送消息、
多 Agent 并发、整机物理断网和多用户生产认证均不属于第一版已完成能力。

## 8. 后台任务演进（已实现首批只读范围）

按 `background-jobs-design.md` 新增持久化任务中心和独立worker。网页仅提交、
查询状态和结果；断开网页不会取消后台任务。服务重启将执行中标记中断，
不自动重放；允许显式重试。首批仅知识/计算及显式启用的只读端口/系统诊断，
不开放任意命令、结束进程、GUI或写文件。后台服务需要持续运行，但不需要
网页或本次开发会话保持连接。

## 9. 确认式AI终端（已实现首批）

按ai-terminal-design独立规划与执行：模型从固定只读目录提议步骤，后端生成
不可变命令/参数/目录/环境计划，用户确认hash后才能启动命令进程。
计划10分钟有效、重复确认幂等、失败不自动改命令。原始stdout/stderr/退出码
与AI解释分别展示。首批目录/Git状态/差异统计/最近提交/版本检查，无任意shell、
脚本测试/安装/写入/联网/提权/PTY；工作区配置不是OS沙箱。

## 7. 运行注意

本机有显著 swap 使用，单次运行一个LLM，嵌入任务限流；不修改系统内存/GPU
限制或关闭安全机制。后台任务需要电脑在线、唤醒并维持后端进程运行，不需要
网页或开发助手会话连接；未确认写入/安装/发布的结果先核对，不能重复执行。
