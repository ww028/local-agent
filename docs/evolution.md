# 项目演进历史

依据仓库提交和既有验收记录整理。以下为开发阶段，不是已发布版本号；实现、自动测试、真实模型验收和开源发布是不同里程碑。

## 1. 从本地聊天开始

`9b62808` 建立项目骨架，`2d7cb87` 打通本地聊天。选择 Web 工作台 + FastAPI + Ollama，先建立流式回答、取消、错误和 SQLite 历史的完整闭环。目标是用户自己掌握推理和资料，不依赖云 API；不建设多人企业服务。

## 2. 从回答到有来源的知识问答

`e4a6ca2` / `3ecf8ee` 增加 Markdown/TXT 导入、结构切片、本地嵌入、LanceDB 与 SQLite FTS5 混合检索及引用预览。SQLite 是业务事实源，向量库是可重建检索副本。Top-K 用于局部证据，不声称能完整总结任意长文。

## 3. 从文本承诺到真实工具事件

`60e9086` / `74e0f7f` 引入有界 Agent 循环和持久化事件；`134c5af` 补证据预算与必需工具完成条件。发现模型会口头回答却漏调用工具，因此以实际成功调用作为完成依据。`b76a41c` 增加会话管理；`6ef08c9` / `2091030` 支持单后端托管本地资源、公式与高亮。

## 4. 从页面请求到持久后台任务

`6305121` / `a4f8a33` 增加后台 worker、队列、取消和显式重试。离开网页不应中断已提交任务，但关机或后端退出并不会继续执行。重启把未知执行标记中断，不自动重放副作用。诊断逐任务授权，范围仍是固定只读能力。

## 5. 从固定动作目录到生成式终端

`c1aa944` / `e3dd941` 最初使用固定只读动作目录和 hash 绑定确认；`1429233` 补端口事实与错误处理。目录无法承载项目测试、文件操作和完整管道，于是 `b08e5d0` / `4cd1410` 转向模型生成真实 exec/argv 或 shell 脚本。能力扩大伴随风险扩大：初始工作区不是 OS 沙箱，授权命令可以访问账号可访问的文件和网络。

## 6. 终端可用性与上下文治理

`d3a75d0` / `f4b5668` 转为会话转录和底部自然语言输入，保留 y/n 确认；`6acff36` 曾尝试对话气泡。后续修正只读反复确认、版本工具链识别、无匹配非零退出、CPU 型号与架构混淆、结果与解释混排：`c507d1f` 至 `7a89dc5`。

确认策略经历“固定调用只读证明 → 脚本分段证明 → 观察意图与副作用检测”。这是减少无意义确认的工程策略，不是任意程序无副作用的形式化证明。未知/误判仍是风险。

`d9a66d8` / `1a70d78` 引入预算和独立终端会话，解决无限堆历史与会话串用。完整本地历史与实际模型输入分开，旧轮次被裁剪不等于记录删除。

## 7. 工作台布局收敛

`fbeeba5`、`f214649`、`13b26a0` 先后尝试独立历史列和不同外壳；`04a67bc` 收敛为单侧栏（导航与最近会话）、中央内容、右侧纵向摘要。删除无功能装饰和重复新建/搜索入口，不把参考布局当功能等价宣称。

`de9943a` 增加只导航的问题目录和聊天上下文用量；`4321c18` 修设置弹层；`0b3f2b0` 补终端会话重命名/删除。浏览器验收发现 CSS 旧列布局残留导致菜单换行、横向滚动、长目录挤走用量；`6d431f8` 修复，并去掉终端气泡/头像，保留命令/输出观感。

## 8. 推理可靠性：从开关到实测

`8a48d5f` 接通快速/深度思考与输出预算，但不能因此宣称正确率提高。洗车、比较、计数和逻辑变式实测暴露模型错误；二次自查也会把正确答案改错。`69c1493` 增加小数/字符的有限精确校验和本地评测脚本，自查流程只留实验，不接正式路由。详见 [推理可靠性](reasoning-reliability.md)。

## 仍需推进

模型横向比较、严格评测判分、精确 tokenizer、长输出证据选择、跨浏览器回归、真实长资料质量、物理断网和安全审计。公开发布前还需新环境安装、许可核对和版本化发布记录。不能以本地 commit 或单次通过代替这些验收。
