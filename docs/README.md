# 文档导航与维护约定

local-agent 是单人单机、本地优先的 RAG + Agent 工作台。项目希望把模型回答、证据检索和真实工具执行放在同一个可检查的界面中，而不是把模型说“做过了”当成执行成功。源码 MIT；模型与依赖保留各自许可。安装可以联网，模型推理在本机；经确认的终端命令仍可能联网，两者不是同一边界。

## 每次改动必须留下什么

- 问题：可公开复现的现象、预期与实际、影响范围。
- 决策：根因证据、考虑过的方案、为何采用或放弃。
- 实现：模块路径、关联提交、兼容与迁移影响。
- 验证：测试类型、环境/模型/参数、实际结论，失败也保留。
- 边界：仍未解决、未验证和可能退化的情况。
- 文档同步：README 能力、架构、专题设计、问题记录、CHANGELOG；路线图只标记真实完成项。

不提交真实数据库、模型权重、私有资料、机器账号路径、凭据、原始隐藏思考或抓取缓存。示例用公开/合成数据。不要把一台机器、一组题、一次截图写成普遍性能或安全保证。
