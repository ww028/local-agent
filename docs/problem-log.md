## 工具与任务

### 模型回答了，却没有执行必需工具｜已修复局部完成判据
- 现象：组合知识搜索/计算任务可能漏调用 calculator。
- 原因：仅靠提示不能保证真实动作发生。
- 决策：Agent 用实际成功工具事件满足必需工具条件，失败/口头承诺不算完成；加步数、调用、时间和证据预算。
- 证据：`134c5af`，`backend/app/agent/`；既有组合任务实测与自动回归。
- 剩余：不保证所有复杂任务都能完成，强制工具不是通用推理增强。

### 关闭页面导致任务生命周期不清楚｜已实现后台生命周期
- 决策：SQLite 持久队列 + lifespan worker；浏览器只轮询。取消持久化，重试建新任务；重启未知运行不重放。
- 证据：`6305121` / `a4f8a33`，`jobs.py`；刷新、换页、取消与重试已有实测。
- 剩余：不是系统守护服务，休眠/关机/退出不持续运行，单实例限制。

### 固定终端目录不能运行真实项目指令｜历史方案已替代
- 决策：生成 exec/argv 或完整 shell 管道，精确计划 hash 和执行前复验；授权风险对用户明示。
- 证据：`b08e5d0` / `4cd1410`，`terminal/plans.py` 与生成式方案。
- 剩余：没有 OS 沙箱、网络防火墙或任意脚本安全证明；不提供 sudo/密码/PTY。

### 只读查询反复弹确认｜已修复已测场景，检测仍有风险
- 曾尝试固定调用/脚本分段只读证明；当前结合观察意图和副作用检测，写入/删除/安装/设置/联网回到确认，执行前复验。
- 证据：`c507d1f`、`9d0eafa`、`7a89dc5`；版本、磁盘和写文件仍确认的实测。
- 剩余：意图识别和命令分析是启发式，不代表任意命令安全。详见终端设计历史。

### 版本查询找错 Python/Node，which 失败阻断｜已修复已测环境
- 决策：解析用户工具链与系统目录；单一版本查询走确定性路径，明确程序/退出码/stderr。
- 证据：`04f037b` / `91980eb`；不依赖工作台 venv 代表用户开发环境。
- 剩余：PATH 和版本会随机器变化；不能提交本机路径/日志当通用样本。

### 无匹配当失败、安装目录遗漏、CPU 架构当型号｜已修复已测场景
- 决策：保留退出码并区分无匹配；清单查询补真实安装目录；型号与架构区分；真实 stdout 先给确定摘要，AI 解释为补充。
- 证据：`1429233`、`c507d1f`、`9d0eafa`；端口/内存/版本回归。
- 剩余：非零不总是无匹配，权限/告警须区分；模型总结仍可能错。

## 上下文与界面

### 历史无限增长、窗口溢出和会话串用｜已实现预算与会话隔离
- 决策：保守 UTF-8 字节预算，预留输出与固定安全余量，按整轮裁最旧模型输入；完整历史保留。单条问题超预算明确拒绝。终端仅本会话最近有限交换。
- 证据：`d9a66d8` / `1a70d78` / `de9943a`，`chat_context.py`、上下文接口。
- 剩余：不是精确 token；历史裁剪可能丢关键前提，未实现自动长期记忆/跨任务摘要。

### 三栏浮卡、重复历史列、菜单换行和水平溢出｜已完成当前视口修复
- 决策：单侧栏 portal + 中央内容 + 右摘要。三点菜单只含重命名/删除；问题目录不能编辑，仅定位。CSS 清除旧 column 排版残留，长标题省略，目录独立滚动，用量保持可见。
- 证据：`04a67bc`、`0b3f2b0`、`6d431f8`；约 952×960 浏览器实测菜单、临时会话重命名/删除、首题定位。
- 剩余：未完成全浏览器/移动端/键盘可访问性矩阵；终端只加载最近30条，目录并非全历史目录。删除当前终端会话会新建空会话。

### 构建更新但页面旧、接口405｜运行态已处理，不是源码功能缺失
- 原因：旧 dist/缓存和旧后端仍监听端口。
- 处理：重新构建；核对监听进程后停止旧实例、按标准启动脚本启动；页面200、新 PATCH 路由对不存在对象返回404而非405。
- 边界：启动脚本不自动接管其他实例；未知写操作结果先核验再重试。此后又有后端提交，发布/验收前仍须检查运行实例版本，不能由一次重启推断一直最新。

## 推理与评测

### 常识/逻辑陷阱题答错｜部分解决
- 开启 think 与加预算没有证实洗车题提升；目标提示仍会错，长思考试验出现重复并达到生成上限。
- 二次审查可修倒置杯，亦会将过河或咨询题改错，未接正式回答。
- 小数比较用 Decimal、ASCII 字符计数逐字符处理，只覆盖完整明确问句；不是硬编码题答案，不是通用算术引擎。
- 证据：`8a48d5f` / `69c1493`，详见 [实验记录](reasoning-reliability.md)。
- 剩余：常识/逻辑仍未解决，其他模型未实测。

### 包含关键词就判正确｜已识别，评测判分未修复
- 例如错误答案“9.11比9.8大”含9.8，拒绝开车的答案也含开车。脚本 marker_match 只能筛查，不能计算正确率。
- 应检查最终结论、方向、理由与对照题；必要时人工标注，不用同一模型自评当真值。
- 当前脚本仍有此局限，不引用其汇总为准确率。
