# 生成式智能终端 V3 技术方案

## 目标与范围纠偏

替代固定动作目录：AI根据用户需求、macOS/Linux平台、可信程序路径和项目目录，
生成实际命令，不需要为内存/磁盘/开发命令逐一添加功能。先展示计划，用户确认
精确内容后执行。保留旧catalog只作历史兼容，不再用于新规划的能力边界。
本项目继续只用公开代码/依赖，本地模型，无企业资源或遥测。

支持两种步骤：exec（program+args直接执行，优先）和shell（必要的管道/重定向/
多条命令完整脚本，明确展示且显式风险确认）。支持系统查询、项目构建/测试、
文件操作、安装或网络命令的计划，不静默运行；有网络可能的计划额外确认联网。
不做sudo/密码/交互式TTY、系统常驻或自动修复重试。服务以当前用户账号运行，
目录限定只约束初始cwd，命令可以访问账号可访问的其他路径，不是OS沙箱。

## 结构与模型规划

新增terminal/plans.py：GeneratedProposal(goal,steps,unsupported_reason)，每步
kind exec/shell、program/args或script、description、timeout_seconds（1–300）。
最多4步，单script8K字符/参数数量64，输入2000字符。模型优先生成最少命令、
不交互、无后台分离、输出有界。内存查询可直接生成sysctl -n hw.memsize，不需要
新的memory动作。Python程序使用当前后端解释器，公开常见开发工具从可信PATH解析。

本地平台信息/工具可用列表仅用于规划，模型不提前执行探测。后端解析程序为
绝对路径并绑定inode/size/mtime；cwd和计划canonical hash仍不可变。shell固定
/bin/bash --noprofile --norc -c，不执行用户shell启动文件、不拼接外层字符串。
未安装程序明确提示，不偷偷安装/调用云。失败允许重新生成命令，但必须新确认。

## 风险、权限与执行

风险评估是保守提示，不是安全判定或沙箱：
- 简单已知只读查询可标低风险；其他exec可能读写/执行项目代码，标“影响待审核”。
- shell/脚本解释器/未知工具标高风险，展示完整文本；安装/发送/删除/覆盖明确提示。
- 网络工具或未知脚本/exec视为可能联网，需额外勾选网络影响确认；不能仅依靠模型
  声明离线。该确认是授权记录，不是OS网络防火墙，必须明确显示此限制。
- 所有V3计划均需确认“本机账号权限、无沙箱”，shell/高风险需要第二项影响确认。
- sudo/su/doas等提权入口和交互密码请求拒绝；不会代输或保存密码。敏感凭据操作
  不作为支持目标；静态检查只能拒绝明显提权/凭据路径，不能证明脚本无隐藏行为。

确认POST绑定hash + risk_acknowledged + high_risk_acknowledged + network_acknowledged，
后端原子校验，页面复选状态按任务hash变化重置。不能用旧只读授权执行V3计划。
排队任务也在执行前重新校验策略/hash/程序身份，未知执行中的重启不自动重放。

执行复用runner：shell=False启动exec或固定bash脚本，最小公开PATH、HOME、TMPDIR
供公开开发工具正常工作，不复制整个环境/代理/令牌。HOME存在意味着本机账号
可能读取凭据，界面必须说明，不声称完全隔离。可配置到另一个可信项目；无需
打开Terminal窗口。每步最多300秒，整单最多约1200秒；stdin=DEVNULL，输出128KiB
每步，超限停止；结束清理本任务进程组，取消不回滚已发生修改。

AI总结独立于命令事实且不能执行；脚本内容/输出均纯文本展示，输出注入不给权限。
零退出码只表示命令完成，不冒充目标成功。只对精确lsof查询使用已有端口事实分类，
不得把其他程序的退出1当无监听。自然语言解析不再强制单数字，支持多目标计划。

## 兼容与交互

V3新任务不依赖ACTIONS枚举；旧已完成记录保留，旧待确认计划可用旧规则查看或
重新规划，但不能继承V3授权。终端能力页面改为生成式范围和权限说明，而非8个动作。
页面显示命令、脚本类型、cwd、每步目的、风险理由/可能影响、联网可能、超时，
有确认复选框、取消、历史/原始输出/AI解释。不开PTY；超时不自动启动后台服务。

## 落地及验收

本方案先写→后端plans/service/confirm/tests自测commit→前端风险确认/文档/真实
本地模型验收commit→模块push。只暂存源文件；真实模型/账号/目录输出仅ignored数据。

必测：内存/sysctl自然语言真实规划执行；不同非枚举exec和公开项目测试；shell
管道+重定向在临时目录；缺少风险/联网确认拒绝；hash/script/argv变动失效、重复
确认只执行一次；取消/超时/输出/重启/非零保留；旧数据迁移；远端/脚本影响提示；
既有聊天/知识/jobs和端口回归。物理断网、恶意脚本安全、长期生产、OS沙箱不认证。
